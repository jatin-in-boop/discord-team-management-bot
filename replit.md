# Discord Team Management Bot

## Project overview

A Discord team-management and community bot built with Python, Discord.py, SQLAlchemy, Alembic, and PostgreSQL. It includes private team channels, protected team-leader roles, persistent button/modal/select interfaces, welcome and goodbye systems, reaction roles, Guild Pulse progression, giveaways, managed-role lifecycle controls, and scheduled recovery tasks.

The bot is deployed as a long-running Railway Docker worker and its source of truth is the public GitHub repository.

## User preferences
